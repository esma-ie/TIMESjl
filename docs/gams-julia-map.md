PR. "Parity" names the reference run and layer each row was checked on.

Every row names its evidence on openly licensed models: the demo12 fixtures
in CI and the reference runs of the public suite models. Before 27 Oct 2026
rows were also checked on models without an open licence; that evidence is
not published (`docs/test-models.md`). "No open-model check yet" marks a
translated path whose evidence is still to be earned on an open model.
