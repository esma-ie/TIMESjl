# Discrepancies

Places where the TIMES GAMS code (v4.9.7, `d9a6a25`) and the TIMES
Documentation disagree. The GAMS code is authoritative; each entry is
reported to ETSAP.

The findings concern the GAMS code and stand on their own. Some were first
seen on reference runs of models without an open licence, which are not
published (`docs/test-models.md`); entries say "no open-model check yet"
until an open model reaches the same code.

## Harness notes

- CONVERT returns model status 14 ("no solution returned"), which
  `err_stat.mod` L56-69 turns into `ABORT` (TIMES `ERR_ABORT` default YES,
  `initsys.mod` L174). The CONVERT run passes `--ERR_ABORT=NO`; the matrix is
  dumped before the check and the generated model is unchanged.
- The PyPI GAMS system (`gamspy_base` 54.6.0, demo licence) runs small models
  with CONVERT, demo CPLEX and HiGHS (`gamspy_highs`, registered into
  `gmscmpun.txt`). Demo-licence size limits apply, so larger models and all
  timings come from a licensed installation.
- Models with families that only appear above the demo licence's size limit get a crafted test case: an openly licensed model plus a DD file kept in `reference/dd/` (suite key `extra_dd_dirs`, searched after `dd_dir`). The crafted cases made before 27 Oct 2026 were built on models without an open licence and are not published; new ones are built on TIMES_Demo demo12 or TIMES-NZ. These cases test the translation; they are not models anyone runs.
- `initmty.mod` L448 sets `VAR_UC YES` when the GAMS licence level is 2 (demo or community licence). A run file that does not set VAR_UC therefore generates the slack form of the user constraints (EQE_UC* = VAR_UC*) under the demo licence and the typed form (EQ(l)_UC* with the right-hand side) under a full licence. demo12 sets `VAR_UC YES`, so its references agree under either licence; for other models, compare references from the same kind of licence.
